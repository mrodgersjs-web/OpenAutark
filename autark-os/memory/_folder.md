# Memory tree

One Markdown file per entry, in folders by who it is for. The files are the truth; whoever edits
a file makes it findable. Start at `company/operating-contract.md` for how this company works.

Folders: `company/` (everyone), `branches/<area>/` (one area), `agents/<id>/` (one agent),
`references/<person>/` (a person's own words), `chats/<chat>/` (one thread).
