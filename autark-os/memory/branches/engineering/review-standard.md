# Review standard

Written 2026-11-23.

- Findings: severity (blocker / high / medium / low), `path:line`, what breaks and under which
  condition, and the smallest fix. No praise, no essays.
- The author never signs off their own work; the reviewer never fixes in the same pass.
- A release is done when the deployed artifact was read back: version, behaviour, rollback path.
- A verify command that already passes is not describing new work.
