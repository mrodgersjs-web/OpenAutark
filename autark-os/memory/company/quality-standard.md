# Quality standard

Written 2026-11-23. This is the line between "we did something" and "it is done".

1. **Named subject.** Every artifact, gate and proof names what it judged (path, id, hash).
2. **A check that could fail.** A verify command, a read-back, a URL fetch - something that
   would have said no.
3. **Coverage stated.** "Tested on macOS only", "happy path only", "one customer's data" - the
   limits are part of the proof, not a footnote.
4. **No invented numbers.** A figure that cannot be traced to a source is deleted, not softened.
5. **A second pair of eyes** on anything hard to reverse: a price, a public claim, a release, a
   security decision.
6. **The next reader can continue** without asking the author anything.
